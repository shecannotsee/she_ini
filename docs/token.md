处理 token 分两步：第一步处理每一行的转义字符；第二步才是处理语义。

### 第一步：处理转义字符

分为这样几个状态

- S1：普通字符状态
- S2：转义字符状态
- S3：行接收状态，也就是一行的内容
- S4：空格状态
- S5：换行状态

对于字符表分为以下几种

- Q1：换行字符 '\n'
- Q2：转义字符 '\\'
- Q3：空格字符 ' '
- Q4：其他字符

对于状态转换模型来说，初始状态是 S1，结束状态是S3

- S1 + Q1 -> S3：**普通字符状态**遇到**换行字符**转换状态为**行接收状态**
- S1 + Q2 -> S2：**普通字符状态**遇到**转义字符**转换状态为**转义字符状态**
- S1 + Q3 -> S4：**普通字符状态**遇到**空格字符**转换状态为**空格状态**
- S1 + Q4 -> S1：**普通字符状态**遇到**普通字符**转换状态为**普通字符状态**
- S2 + Q1 -> S1：**转义字符状态**遇到**换行字符**转换状态为**普通字符状态**
- S2 + Q2 -> S1：**转义字符状态**遇到**转义字符**转换状态为**普通字符状态**
- S2 + Q3 -> S2：**转义字符状态**遇到**空格字符**转换状态为**转义字符状态**
- S2 + Q4 -> S1：**转义字符状态**遇到**普通字符**转换状态为**普通字符状态**
- S4 + Q1 -> S3：**空格状态**遇到**换行字符**转换状态为**行接收状态**
- S4 + Q2 -> S2：**空格状态**遇到**转义字符**转换状态为**转义字符状态**
- S4 + Q3 -> S4：**空格状态**遇到**空格字符**转换状态为**空格状态**
- S4 + Q4 -> S1：**空格状态**遇到**普通字符**转换状态为**普通字符状态**
- S5 + Q1 -> S3：**换行状态**遇到**换行字符**转换状态为**行接收状态**
- S5 + Q2 -> S2：**换行状态**遇到**转义字符**转换状态为**转义字符状态**
- S5 + Q3 -> S4：**换行状态**遇到**空格字符**转换状态为**换行状态**
- S5 + Q4 -> S1：**换行状态**遇到**普通字符**转换状态为**普通字符状态**

### 第二步：处理语义

在经过第一步以后，此时就只有有用的字符了，并且是按行分隔，易于处理。
